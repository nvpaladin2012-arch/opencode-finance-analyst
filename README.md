# finance-analyst — финансовый ИИ-агент для OpenCode

🌐 **Страница агента в браузере:** https://nvpaladin2012-arch.github.io/opencode-finance-analyst/

Агент OpenCode (V2), который по запросу собирает и структурирует актуальные котировки:

- 🇺🇸 **USD/RUB** — официальный курс ЦБ РФ и рыночная котировка;
- ₿ **BTC** — цена в USD и RUB, изменение за 24 ч;
- Ξ **ETH** — цена в USD и RUB, изменение за 24 ч;
- 📈 **IMOEX** — значение в пунктах, изменение за день и статус торгов.

## Ключевые правила агента

- обязательный веб-поиск (`websearch`) и/или загрузка страниц (`webfetch`) при каждом запросе котировок — данные из памяти не используются;
- приоритетные источники: cbr.ru, moex.com, РБК Инвестиции, Investing.com, TradingView, CoinMarketCap, CoinGecko, Binance, Bybit;
- проверка даты и времени публикации; заголовок сводки — по МСК (UTC+3);
- если торги закрыты (выходные/праздники), явно указывается статус и данные последней торговой сессии;
- если источник недоступен — «н/д» вместо вымышленных цифр;
- единый шаблон ответа и округление: валюты/индекс — 2 знака, криптовалюты — целые или 2 знака;
- никаких инвестиционных рекомендаций, только нейтральные факты и дисклеймер.

## Установка

### Вариант 1 — только для одного проекта

Скопируйте файл в корень вашего проекта:

```text
<проект>/.opencode/agents/finance-analyst.md
```

### Вариант 2 — для всех проектов (глобально)

Скопируйте файл по пути:

```text
~/.config/opencode/agents/finance-analyst.md
```

На Windows: `C:\Users\<вас>\.config\opencode\agents\finance-analyst.md`.

Перезапуск OpenCode не требуется: конфигурация перезагружается автоматически, для принудительной перезагрузки — `/reload`.

## Использование

Попросите основной агент запустить саб-агент:

```text
Используй finance-analyst и дай текущую финансовую сводку.
```

Или выберите `finance-analyst` как основной агент сессии (поле `mode: all` поддерживает оба режима).

## Доступ в интернет

Права на `websearch` и `webfetch` уже прописаны в frontmatter агента. Если в вашей среде веб-поиск не настроен, добавьте в `opencode.jsonc`:

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "websearch": {
    "provider": "random"
  }
}
```

## Пример ответа

```text
📊 Финансовая сводка на 23 ноября 2026, 14:30 МСК

* 🇺🇸 Доллар (USD/RUB):
  * Курс ЦБ РФ: 92,45 ₽
  * Рыночный курс: 92,70 ₽ (-0,12%)
* ₿ Биткоин (BTC): $86 240 (~7 987 428 ₽) | +1,34%
* Ξ Эфириум (ETH): $2 910 (~269 487 ₽) | +0,87%
* 📈 Индекс Мосбиржи (IMOEX): 2 745,32 п. | -0,41% (Статус: Закрыты)

💡 Краткий контекст: ...
```

> Цифры в примере иллюстративные. Агент всегда получает актуальные значения через веб-поиск.

## Дисклеймер

Агент предоставляет только информацию о рынке и не является источником инвестиционных рекомендаций.
